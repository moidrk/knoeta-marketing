# Knoeta marketing direction

## Source reconnaissance

The authoritative source is `moidrk/knoeta-clinical`, inspected read-only in the adjacent clinical checkout. Read README, current PROGRESS, global tokens, layout, brand config, dashboard, training, simulations, competency, progress, coach, library, product shell, chart components, and authored coaching content. The current progress document and implemented routes take precedence over stale README summaries.

Product loop: review evidence → practice a decision → explain reasoning → accumulate competency evidence → repeat. Public representations abstract this into Simulation, Expert Guidance, and Judgment Over Time. No case titles, treatment instructions, patient records, scoring mechanics, personal identities, or performance statistics are carried into marketing.

## Brand and system

- Actual production violet: `oklch(0.47 0.24 276)` from clinical globals.
- Approved orbital mark: `public/logos/knoeta_small.png`; paired with a Geist wordmark for the parent Knoeta brand. The concept's three-dot mark is not an approved asset.
- Geist via next/font; typography is generous and uses deliberate desktop line breaks.
- Warm ivory canvas, aubergine ink, persimmon emphasis, dusty lilac, mineral sage.
- One rounded atmospheric hero, editorial white transition, alternating large product stories, a full-width trajectory, compact growth philosophy, a dawn close.
- Signature motif: three initially separate paths become a shared trajectory. It is a conceptual illustration, not a plot of product outcomes.
- Hero uses CSS light fields and SVG trajectories as expressly requested in the brief; live marketing UI is purpose-built DOM, not a flattened image.
- The image is art direction, not a screenshot specification. The user's explicit Next.js foundation and new marketing design system supersede plugin starter/fidelity defaults.

## Implementation plan

Server-render page structure and static representations. Limit client components to menu, small interaction demos, Motion reveal wrappers, and animated trajectories. Keep content visible without animation. SVG/CSS for the intelligence field, generated optimized landscape for the final visual. Desktop product stage rises under the headline; tablet loses support fragments; mobile replaces the wide product layout with one readable primary panel. Navigation anchors map to real sections; product CTAs go to clinical.knoeta.com. No video CTA without an actual video.
